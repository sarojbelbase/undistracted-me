# Keyword Research: Nepali extension & focus new tab

Research date: Nov 25, 2026. Source: live SERPs (web search), since the OpenSEO
MCP tracker is not connected in this environment.

## Headline finding

The "Nepali calendar new tab" niche that Undistracted Me started in is now
crowded. Direct Chrome Web Store competitors now include **Tabre**, **Namaskar**,
**Miti**, "Nepali Calendar" and "Nepali Date & Calendar", and **Hamro Patro**
ships its own Chrome extension. Undistracted Me's CWS tagline ("distraction free
nepali date") is now one of many.

The moat is the **focus angle**: site blocker + Pomodoro + widgets, which none
of the Nepali-calendar competitors offer.

## Recommendations

1. **Own the "nepali extension" / "made in Nepal" cluster.** Low competition, no
   list article yet, and we are already indexed under the GitHub topics. Added
   to JSON-LD keywords + ARD representative queries.
2. **Differentiate the CWS listing.** Lead with "focus new tab + site blocker",
   not "nepali date", to stand out from Tabre / Namaskar / Miti.
3. **Get listed in roundups** for "best new tab / focus / site blocker
   extension": daily.dev, speeddial2.com, browsers.to, meelio.io,
   web-highlights.com, zapier.com, focusmode.app/alternatives.
4. **Watch Tabre and Miti.** Both market hard on r/Nepal. Match with our own
   "built in Nepal, for focus" positioning (the "no Nepal in visible body" rule
   currently limits this, see MARKETING-NEXT-STEPS.md item 4).

## The "best nepali extension" play

There is no "best Nepali extension" list article today, so the query is served
by Chrome Web Store listings + Reddit. Being the clearest answer for it is a
cheap, on-brand win: our GitHub description already reads "a chrome/firefox
extension that replaces your new tab with minimal & distraction-free pages,
made in Nepal."
