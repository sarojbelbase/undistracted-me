UNDISTRACTED ME — REVIEWER NOTES
Extension ID: {1071d037-0f17-4c92-b06c-704050d2e2c3} · Version: 4.0.0

WHAT IT IS
Replaces the new tab with a calm dashboard: Nepali (Bikram Sambat) calendar,
Focus Mode (full-screen clock + rain sounds), and 30+ optional widgets (notes,
expenses, countdowns, NEPSE stocks, weather, Pomodoro, media, RSS). No
account/ads/tracking; data stays on-device. Open source (MIT).

BUILD
bun run build:firefox → dist-firefox/
Source is unminified (Vite + @crxjs/vite-plugin, MV3). No eval or remote
code; CSP script-src 'self'.

OAUTH — no shared client secret
- Google: PKCE via chrome.identity.launchWebAuthFlow; code exchanged
  server-side at https://api.undistracted.me/auth/google/token (validates
  redirect_uri allowlist + PKCE code_verifier). Bundle has only the public
  client ID; client_secret lives only in the backend env.
  src/utilities/googleAuth.js, functions/auth/google/token.js
- Spotify: PKCE client-side, exchanged directly with Spotify (never via our
  servers). Tokens in chrome.storage.local (never localStorage).
  src/widgets/media/

PERMISSIONS
identity → Google/Spotify OAuth
storage → widget settings + OAuth tokens (chrome.storage.local for sensitive)
geolocation → weather (prompts user before read)
topSites → Quick Access widget
notifications → event reminders, Pomodoro, look-away breaks
alarms → event checks, timers, RSS prefetch
idle → LookAway idle/locked check
tabs → media-controls relay: find the tab with an active media session to
       route play/pause/next and inject media.js into open YouTube/SoundCloud
       tabs. URLs/titles read for routing only; no history stored.
scripting → inject media.js into already-open YouTube/SoundCloud tabs
declarativeNetRequest → Website Blocker (Focus Mode); dynamic rules (IDs
       1000+), user-configured only (src/utilities/siteBlocker.js)

HOST PERMISSIONS
Scoped to contacted origins only (YouTube/SoundCloud, Spotify, Google APIs,
weather/geolocation, stocks, search-suggest, jokes, undistracted.me API).
No <all_urls> / *://*/* grant.

CONTENT SCRIPTS
YouTube + SoundCloud (media.js, document_idle): polls mediaSession, routes
MEDIA_ACTION commands. Messages allowlist-validated. No innerHTML, eval, or
data exfiltration.

WEB-ACCESSIBLE RESOURCES
entries/blocked.html (+ assets/blocked*) exposed on <all_urls> as the Focus
Mode "site blocked" interstitial (required for the DNR redirect). Static,
non-privileged; ?d= validated against a strict hostname regex. A site can
probe the pinned ID to detect install (accepted; no data leaks).

THIRD-PARTY SERVICES
Weather (open-meteo.com); IP geolocation fallback (nominatim, freeipapi.com,
ipapi.co — only if geolocation unavailable AND weather on; in privacy policy);
stocks (nepalipaisa.com, merolagani.com); Spotify; Google APIs; search
(Google/DDG); jokes (icanhazdadjoke.com); backend (api.undistracted.me: FF
token exchange, photos, favicon, RSS proxy).
